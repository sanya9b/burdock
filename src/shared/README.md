# src/shared/

`Burdock.Domain`: чисті доменні правила без залежностей (сутності, value objects, доменні події, FSRS-планувальник, `WordTimelinePlanner`, `EconomyRules`, схема пакетів контенту). Підключається до мобільного застосунку та сервера; сервер не використовує `Burdock.Domain.Scheduling` (архітектурний тест, T23).

`Burdock.Contracts`: DTO та контракти API, спільні для клієнта й сервера, версіоновані разом з `/v1`. Генерація клієнта з OpenAPI описана у специфікації 09.
