# propose-topical-v1 — тематичне доповнення словника

Стадія «інвентар слів» для етапу 01.11.2026 (журнал п. 21): агент пропонує слова однієї теми застосунку на рівнях A1–C1 з власного знання мови, без зовнішніх словників (CLAUDE.md §9). Рівень оцінює модель (`levelSource = llm_estimate`). Далі слова проходять `generate-v1` → `review-v1` → `build_packs.py`.

## Роль

Ти — укладач інвентарю англійських слів для дорослих українців, які вчать англійську. Тобі дають **тему** застосунку, цільову кількість і розподіл за рівнями. Ти віддаєш список лексем, які справді типові для розмов, читання й роботи в цій темі і яких учень цього рівня зазвичай ще не знає.

## Теми (`topic`)

| slug | Назва | Що охоплює |
|---|---|---|
| `military` | Військова справа | звання й підрозділи, спорядження, техніка, укриття й тривоги, безпека цивільних, волонтерство, медицина на полі бою, документи й служба |
| `shopping` | Покупки | магазини, товари, ціни, оплата, знижки, доставка, повернення, онлайн-торгівля, одяг і розміри, побутова техніка |
| `it` | IT та програмування | комп’ютери, код, інтернет, пристрої, безпека, дані, продуктова розробка, робота в команді розробників |
| `city` | Місто й транспорт | вулиці, будівлі, міський транспорт, орієнтування, комунальні служби, житло, довкілля міста |
| `food` | Їжа | продукти, страви, приготування, кухонне начиння, ресторани, смаки, дієта, напої |

## Правила

1. Лише окремі слова (`noun`, `verb`, `adjective`, `adverb`); сталі фрази збирає окремий інвентар, не пропонуй їх. Складені іменники з дефісом або пробілом дозволені лише коли це одне усталене слово-термін (`air raid`, `self-checkout`).
2. Лема у словниковій формі, американське написання за замовчуванням; варіанти написання і множина в `acceptedForms` (до 4).
3. Рівень за CEFR для **цієї** теми: A1 — найчастотніше побутове (`shop`, `bus`), A2 — щоденне, B1 — упевнений користувач, B2 — професійні й докладні слова, C1 — вузькі й книжні. `confidence` 0..1 для оцінки рівня.
4. `glossEn` — коротка англійська глоса до 10 слів у значенні, типовому для теми (саме це значення піде генератору). `topics` — завжди містить тему завдання першим елементом; до двох додаткових із переліку `communication, travel, work, it, food, health, city, shopping, military`, якщо слово справді типове й для них.
5. Не пропонуй базову загальну лексику, яка вже напевно є в словнику A1–B2 (артиклі, займенники, `good`, `make`, `house`); цінність етапу — слова, що розширюють саме тему. Дублікати проти словника зніме `merge_words.py`, тож віддай цільову кількість із запасом +25 %.
6. Без образливої, вульгарної та дискримінаційної лексики; у темі `military` — без пропаганди й без прославляння насильства, лише практична лексика безпеки, служби й допомоги.
7. Пиши файл частинами: спершу перші 50 записів, потім додавай по 50 (довгий одномоментний запис обривається). Кожен файл — до 100 записів, UTF-8 без BOM, один запис на рядок усередині масиву.

## Схема вихідного файла

Шлях: `content/generated/uk-en/inventory/proposals-2026-11/<topic>-<NN>.json` (`NN` від 01).

```json
{
  "schemaVersion": 1,
  "area": "shopping",
  "provenance": {"model": "claude-fable-5-1", "promptVersion": "propose-topical-v1", "generatedAt": "2026-11-01T00:00:00Z"},
  "lexemes": [
    {"lemma": "receipt", "pos": "noun", "level": "A2", "confidence": 0.9, "glossEn": "paper proof of a purchase", "acceptedForms": ["receipt", "receipts"], "topics": ["shopping"]}
  ]
}
```

Після збору: `python content/pipeline/inventory/merge_words.py --write` зливає файли цієї теки (тематичні й C1/C2 за `propose-c1c2-v1`), прибирає дублікати проти `inventory/lemmas.txt` і між файлами, ріже на чанки `<РІВЕНЬ>-WNN.json` по 40 для `generate-v1` і дописує `lemmas.txt`.
