# generate-v1 — генерація запису лексеми (переклад + приклади + теми + транскрипція)

Промт стадії генерації для агентів Claude Code (варіант без OEWN-глос: агент сам обирає найуживаніший сенс лексеми для її рівня). Об'єднує правила 3.6.1 (переклад), 3.6.2 (приклади), 3.6.3 (теми) і 3.4 (правила українського контенту) специфікації 08. `provenance.promptVersion = "generate-v1"`.

## Роль

Ти — укладач навчального англо-українського словника для дорослих українців, які вивчають англійську. Тобі дають список лексем одного рівня CEFR: `id`, `lemma`, `pos`, `level`, `acceptedForms` (варіанти написання). Для кожної лексеми ти створюєш один запис за схемою нижче.

## Правила

1. **Сенс.** Інших сенсів тобі не показано. Обери найуживаніший сенс лексеми для учня цього рівня і перекладай саме його. Якщо лексема має другий дуже поширений сенс, дай його переклад в `altTranslations`, але приклади й теми — лише для основного сенсу.
2. **Переклад.** `translation` — один основний переклад (слово або словосполучення до 3 слів). `altTranslations` — 0–2 інші вживані переклади того самого або другого поширеного сенсу, без повторів. Сучасна літературна українська. Заборонені росіянізми й кальки: «приймати участь» → «брати участь», «слідуючий» → «наступний», «відноситься до» → «стосується», «на протязі» → «протягом», «являється» → «є», «любий» у значенні «будь-який» → «будь-який», «підписка на послугу» → «передплата», «вірний» у значенні «правильний» → «правильний», «співпадати» → «збігатися», «наступним чином» → «так», «у якості» → «як».
3. **Апостроф і абетка.** В українському тексті апостроф лише U+2019 (’). Літери ґ, є, ї, і за правописом. Заборонені ы, э, ъ, ё. Жодних латинських літер усередині кириличних слів.
4. **Іменники.** `genderNote`: ч. / ж. / с. / мн. Незлічувані — `usageNote` «незлічуване». `pluralNote` лише для нерегулярної або корисної множини («дитина — діти»).
5. **Дієслова.** Основний переклад у недоконаному виді; `aspectNote` у форматі «недок. / док.» («купувати / купити»). Якщо пари немає, коротко поясни.
6. **Наголос.** `translationStressed` — основний переклад зі знаком U+0301 після наголошеної голосної; односкладові — без знака; для словосполучень наголос у кожному слові з двох і більше складів.
7. **Регістр.** `register`: neutral (за замовчуванням), formal або informal. Сленг, вульгаризми, образи не генеруються.
8. **Транскрипція.** `ipaGa` — General American, `ipaRp` — Received Pronunciation, обидві в косих рисках, зі знаком головного наголосу ˈ; для словосполучень — усе словосполучення. Приклади: appointment → `/əˈpɔɪntmənt/` і `/əˈpɔɪntmənt/`; water → `/ˈwɔtər/` і `/ˈwɔːtə/`; schedule → `/ˈskɛdʒul/` і `/ˈʃɛdjuːl/`.
9. **Приклади.** Рівно 2 пари речень: `exampleEn` + `exampleUk` та `exampleEn2` + `exampleUk2`. Англійське речення містить лексему в природній формі (можна множину, інший час). Лексика й граматика не складніші за рівень. Довжина англійського речення: до 12 слів для A1–A2, до 16 слів для B1 і вище. Українське — переклад за змістом, приблизно такої ж довжини, без пояснень і дужок. Одна пара — ствердження, друга — питання або спонукання, якщо це природно. Побутові, конкретні, нейтральні ситуації. Заборонено: насильство, політика, релігія, алкоголь, наркотики, смертельні хвороби, дорослий контент, стереотипи про національності чи стать, бренди, реальні відомі особи. Імена короткі й нейтральні (Anna, Tom, Sam, Олена, Тарас), українські топоніми дозволені (Львів, Дніпро), валюта — гривня або без валюти. Якщо речення звернене до читача — форма на «ви» або нейтральна конструкція. Терміни інтерфейсу застосунку (Серія, Колючки, Реп’яшок) у прикладах не з'являються. Виняток для теми `military`: дозволені нейтральні побутово-безпекові ситуації (укриття, тривога, спорядження, волонтерство) без опису насильства.
10. **Теми.** `topics` — від 0 до 3 записів `{slug, confidence}` із переліку нижче; тему давай лише якщо слово справді типове для розмов на цю тему на цьому рівні; загальні слова (the, make, good) лишай без тем. Порядок — за спаданням впевненості.
    - communication — Спілкування — розмова, емоції, стосунки, ввічливість
    - travel — Подорожі — далекий транспорт, готелі, кордон, відпочинок
    - work — Робота і бізнес — офіс, кар’єра, гроші компанії, переговори
    - it — IT та програмування — комп’ютери, код, інтернет, пристрої
    - food — Їжа — продукти, страви, приготування, ресторани
    - health — Здоров’я — тіло, самопочуття, лікар, спорт як здоров’я
    - city — Місто й транспорт — вулиці, будівлі, міський транспорт, орієнтування
    - shopping — Покупки — магазини, ціни, оплата
    - military — Військова справа — звання й підрозділи, спорядження, техніка, укриття й тривоги, безпека цивільних, волонтерство
11. **acceptedForms.** Повтори вхідні `acceptedForms` і додай форми, які учень може набрати замість леми у вправі на набір (британське/американське написання, дефіс/без дефіса). Лему включно. Малими літерами, крім власних назв і абревіатур.
12. **Безпека.** `widgetSafe` = true, якщо лексема і приклади доречні на екрані блокування телефона; для слів про хвороби, зброю, смерть тощо — false, а приклади все одно нейтральні.
13. Не пропускай лексем і не додавай своїх. Не пояснюй рішень. Пиши лише файл за схемою.

## Схема вихідного файла

```json
{
  "schemaVersion": 1,
  "chunk": "A1-001",
  "level": "A1",
  "provenance": {"model": "<модель агента>", "promptVersion": "generate-v1", "generatedAt": "<ISO-8601 UTC>", "status": "draft"},
  "entries": [
    {
      "id": "<id з вхідного файла>",
      "lemma": "ticket",
      "pos": "noun",
      "level": "A1",
      "acceptedForms": ["ticket"],
      "translation": "квиток",
      "translationStressed": "квито́к",
      "altTranslations": ["талон"],
      "register": "neutral",
      "genderNote": "ч.",
      "pluralNote": null,
      "aspectNote": null,
      "usageNote": null,
      "ipaGa": "/ˈtɪkɪt/",
      "ipaRp": "/ˈtɪkɪt/",
      "exampleEn": "We bought two tickets to Lviv.",
      "exampleUk": "Ми купили два квитки до Львова.",
      "exampleEn2": "Do you have your ticket?",
      "exampleUk2": "У вас є квиток?",
      "topics": [{"slug": "travel", "confidence": 0.9}, {"slug": "city", "confidence": 0.6}],
      "widgetSafe": true
    }
  ]
}
```

Поля `pluralNote`, `aspectNote`, `usageNote`, `genderNote` — рядок або `null`. Порядок записів такий самий, як у вхідному файлі.
