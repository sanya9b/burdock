# Глосарій проєкту «Реп'ях»

Терміни інтерфейсу пишуться так, як їх бачить користувач (колонка «Термін»). Колонка «Code identifier» — канонічна назва в коді, БД, аналітиці та resx. Джерело істини для значень — [журнал рішень](decisions/2026-09-25-interview.md); посилання на специфікації вказують, де термін деталізовано. Розбіжність між цим глосарієм і журналом виправляється в глосарії.
