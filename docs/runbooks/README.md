# Runbook-и

Покрокові операційні процедури (спека 16 FR-16-13, спека 14 §3.12). Кожен runbook має передумови, кроки з командами, перевірку результату, відкат, час виконання і правило ескалації. Після кожного використання runbook правиться, якщо кроки розійшлися з реальністю.

| Runbook | Коли | Стан |
|---|---|---|
| [release-ios.md](release-ios.md) | реліз iOS у TestFlight: сертифікати без Mac, секрети `prod-ios`, запуск з тегу `mobile/v*`, перевірка, відкат | готовий, чекає на перший реальний прогін |
| deploy.md | деплой сервера на Hetzner (`publish-server` → `deploy-server`) | після створення VM |
| rollback.md | відкат сервера на попередній образ і міграції | після першого деплою |
| restore-backup.md | відновлення PostgreSQL з pgBackRest, щомісячне тренування (T26) | після налаштування pgBackRest |
| rotate-keys.md | ротація ключів OpenIddict, API-ключа App Store Connect, SSH-ключа деплою, S3-ключів | після деплою |
