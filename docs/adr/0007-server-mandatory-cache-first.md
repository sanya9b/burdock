# 0007. Сервер обов'язковий, контент кешується після першого запуску

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-27 |
| Рішення журналу | Q4, Q13, Q14, T8 |
| Специфікації | 09, 01, 08 |

## Контекст

Власник хоче, щоб сервер був авторитетним для контенту, нагород і підписок, але застосунок має працювати у метро й при відключеннях світла після першого запуску. Сервер має сам відстежувати оновлення контенту й синхронізувати їх.

## Варіанти

1. Повністю офлайн без сервера. Суперечить Q4.
2. Онлайн-only без кешу. Непридатно для українських реалій.
3. **Онлайн для першого запуску, покупок і зміни рівня/категорій; далі все працює з кешу, синхронізація при появі мережі; клієнт перевіряє маніфест контенту (ETag) при запуску, поверненні на передній план і у фоновому оновленні.**

## Рішення

Варіант 3. Прогрес і нагороди пишуться локально в append-only журнали та відправляються через outbox. Сервер авторитетний для entitlement-ів і звірки нагород. Push-тригер оновлення контенту (APNs/FCM) додається у v1.1.

## Наслідки

Віджети й сповіщення ніколи не залежать від мережі. Кеш містить лише пакети обраних рівня/категорій і безкоштовний пул. Потрібні чіткі UI-стани «потрібен інтернет».
