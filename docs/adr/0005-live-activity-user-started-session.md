# 0005. Live Activity лише як сесія, запущена користувачем

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-27 |
| Рішення журналу | Q35, Q1 |
| Специфікації | 04, 03, 09 |

## Контекст

Власник хоче Live Activity / Dynamic Island. Apple HIG забороняє Live Activity без живої події, а правило App Review 4.5.3 дозволяє відхилити пасивну «стрічку слів». Дозволена активність, яку користувач сам запускає і яка показує прогрес із чітким завершенням.

## Варіанти

1. Пасивна стрічка слів попри ризик відмови.
2. Перенести у v1.1.
3. **Сесія у v1: користувач запускає її вручну на 1-8 годин, слова змінюються по черзі, є прогрес і кнопка завершення.**

## Рішення

Реалізуємо варіант 3 у v1. Зміна слова відбувається кнопкою «Далі» (LiveActivityIntent, iOS 17+) та автоматично за розкладом через push-оновлення ActivityKit з сервера (APNs), із деградацією до ручного режиму без push. Текст для App Review описує, що активність запускає користувач і вона показує прогрес сесії.

## Наслідки

Сервер отримує модуль Notifications з APNs уже у v1 (пуш-оновлення контенту залишаються у v1.1). Потрібен окремий Swift-таргет ActivityKit у тому ж розширенні. Сесія обмежена 8 годинами за правилами системи.
