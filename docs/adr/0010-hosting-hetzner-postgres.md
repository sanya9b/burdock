## Контекст

Дані користувачів мають зберігатися в ЄС, бюджет соло-розробника обмежений, стек .NET.

## Варіанти

1. **Hetzner Cloud Falkenstein/Helsinki, одна VM на старті, Docker Compose (api, postgres:18, caddy, pgbackrest), Hetzner Object Storage + Bunny CDN для пакетів контенту.** Приблизно 12-20 євро/міс на 1 тис. користувачів.
2. Azure Container Apps + PostgreSQL Flexible у West Europe. Керовані сервіси, у 3-10 разів дорожче.
3. PaaS (Fly.io/Railway). Простіше, менше контролю.

## Рішення

Варіант 1 з підписаною DPA Hetzner, резервними копіями у другій локації (pgBackRest) і шляхом міграції на Azure без переписування коду (контейнери, EF Core, без залежності від специфічних сервісів).

## Наслідки

Операційна відповідальність на розробнику: оновлення ОС, бекапи, моніторинг. Runbook-и обов'язкові. Масштабування вертикальне, потім друга VM.
