# 0002. iOS спершу, Android зі спільної кодової бази пізніше

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-27 |

| Специфікації | 01, 05, 17 |

## Контекст

Власник хоче спершу iPhone. Розробка ведеться на Windows, де iOS не запускається локально, а Android-емулятор є єдиним способом побачити застосунок щодня.

## Варіанти

1. Лише iOS до підтвердження попиту. Мінус: жодного локального запуску на Windows.
2. **Спільна база з дня 1, реліз Android через 1-2 місяці після iOS.** Плюс: щоденний цикл на емуляторі, платформові дефекти видно рано. Мінус: трохи більше роботи на старті.
3. Одночасний реліз. Мінус: подовжує шлях до першого релізу.

## Рішення

Android-проєкт компілюється й тестується з першого дня; функціональність, яка не залежить від платформи, перевіряється на емуляторі. Публікація в Google Play через 1-2 місяці після App Store; Android-віджети реалізуються після iOS-віджетів. Мінімум Android API 26, target API 36.

## Наслідки

Порти платформи проєктуються одразу для обох ОС. iOS-специфіка (WidgetKit, ActivityKit) перевіряється лише в CI та TestFlight. Дорожня карта містить окрему фазу Android.
