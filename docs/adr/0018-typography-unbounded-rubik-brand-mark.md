# 0018. Типографіка Unbounded + Rubik замість Fixel; брендовий знак і анімований екран завантаження

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-28 |
| Рішення журналу | T6 (змінено в частині шрифту), Q8, Q19, Q20; зауваження власника 28.09.2026 («шрифт сируватий», «прибрати стандартні значки й екрани завантаження .NET, зробити свої анімовані з маскотом») |
| Специфікації | 02 (§3.2, §3.4), 03 (S-01) |
| Змінює | ADR 0013 у частині гарнітури (токени та генератор лишаються джерелом істини) |

## Контекст

Fixel (T6) закрив вимоги до кирилиці й ліцензії, але на екранах мови v2 (ADR 0017) виглядав нейтрально: власник назвав його «сируватим» при схваленому стилі. Паралельно застосунок досі мав іконку й заставку шаблону .NET MAUI, що суперечить §3.2 дизайн-системи та принципу «маскот там, де є емоція».

Кандидатів перевірено на реальних рядках застосунку (`design/typography/font-candidates.png`): Unbounded, Rubik, Geologica, Nunito, Wix Madefor Display, Onest, Manrope, Comfortaa, Marmelad, Montserrat, Sofia Sans; Jost відпав через відсутність ґ є і ї. Усі — OFL без Reserved Font Name (дозволяє статичні інстанси зі збереженням назв), жоден не належить російській словолитні (політика §3.4): Unbounded — NaN (Париж), Rubik — Hubert & Fischer.

## Варіанти

1. Залишити Fixel, підсилити характер лише кольором і формою.
2. Одна виразна родина на все (Rubik або Geologica).
3. **Пара: Unbounded для дисплейних ролей (display, headline lg/md, word.hero, numeric.stat) + Rubik для тексту, підписів і кнопок.**

## Рішення

Варіант 3.

1. **Гарнітури.** `typography.fontFamily.display = Unbounded`, `typography.fontFamily.text = Rubik`. У застосунок вбудовуються статичні інстанси змінних шрифтів (fontTools instancer, `D:\tmp\burdock\fonts\make_static.py` — інструмент разовий, результат у `Resources/Fonts`): Rubik Regular/Medium/SemiBold/Bold, Unbounded SemiBold/Bold/ExtraBold, ліцензії поруч. Аліаси MAUI виводяться генератором з назви родини та ваги (`Rubik`, `RubikSemiBold`, `UnboundedBold`…), тож зміна шрифту — це зміна двох токенів і файлів, без правок XAML.
2. **Ролі.** Шкала розмірів і ваг не змінюється; Unbounded ширший, тому довгі заголовки переносяться на два рядки, а слово-герой обрізається `TailTruncation` лише після 13+ літер (перевірено на «Доброго ранку», «Твоя бібліотека порожня», «Сесію завершено»).
3. **Брендовий знак.** `design/mascot/build_brand_assets.py` генерує з геометрії маскота: іконку (фон-градієнт violet.600 → violet.800 + реп’яшок із двома очима, без брів і рота — читається від 29 px), заставку та Android VectorDrawable. `ForegroundScale=0.75` тримає гачки в безпечній зоні адаптивної іконки.
4. **Екран завантаження.** Android 12+: системна заставка показує анімований векторний знак (гачки гойдаються, знак підстрибує, очі кліпають, 1000 мс) на `color.widget.background`; `MainActivity` тримає її до кінця анімації (`ISplashScreenOnExitAnimationListener`), плавно прибирає й сигналізує сторінці через `ISystemSplash`, тому мінімальний час показу S-01 рахується вже після зникнення системної заставки. Розмір знака на S-01 (`size.brandMark.splash` = 126 pt, `brand_mark.svg` обрізаний по межах знака) виміряно на емуляторі, щоб перехід був без стрибка. Далі на обох платформах — сторінка S-01 `BootstrapPage` з тим самим знаком, маскотом `joy`, статусом «Готую твої перші слова…», логотипом і теглайном; маскот погойдується циклом 1,4 с, під Reduce Motion (Android «прибрати анімації», iOS Reduce Motion через `IMotionPreferences`) статичний. Мінімум показу 900 мс, потім плавна передача вікна Shell-у. Помилка підготовки — стан error з кнопкою «Спробувати ще раз».

## Наслідки

- Плюс: упізнавана типографіка з характером; іконка, заставка й перший екран одна сцена; шрифт можна замінити токенами.
- Мінус: два файли Unbounded по 400 KB (три ваги — 1,2 MB) збільшують пакет; за потреби підмножина латиниця+кирилиця. Ширина Unbounded вимагає перевіряти довгі заголовки в кожному новому екрані.
- Анімована системна заставка є лише на Android 12+; iOS показує статичний знак до появи `BootstrapPage` (LaunchScreen не анімується).
- Debug-збірка MAUI стартує ~5 с, і після передачі вікна Shell-у екран «Сьогодні» ~1 с порожній до першого кадру; у release зі збіркою AOT це коротше, але скелетон екрана «Сьогодні» лишається боргом.
- Перевірка: запис екрана емулятора (`adb shell screenrecord`) і розкладка кадрів — `design/preview/screenshot-android-launch-sequence.png`.
- Спека 02 §3.4 і README оновлено; ADR 0013 лишається чинним щодо токенів та іконок Lucide.
