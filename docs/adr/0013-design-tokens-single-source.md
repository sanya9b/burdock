# 0013. Дизайн-токени як єдине джерело істини; шрифт Fixel та іконки Lucide

| Поле | Значення |
|---|---|
| Статус | Accepted |

| Рішення журналу | Q8, Q19, Q20, T6, T19, T20 |
| Специфікації | 02 |

## Контекст

Інтерфейс рендериться трьома технологіями: MAUI XAML, SwiftUI у WidgetKit і Android RemoteViews. Власник вимагає високої якості дизайну, світлої й темної тем і доступності. Потрібна українська типографіка з ґ, є, ї та апострофом.

## Варіанти

1. Кольори й стилі вручну в кожній технології. Розсинхронізація гарантована.
2. **Тришарові токени (primitive → semantic → component) у `design/tokens/tokens.json` (формат W3C DTCG), з яких генеруються Colors.xaml/Styles.xaml, Swift і Android XML; шрифт Fixel (OFL, повна українська кирилиця), іконки Lucide (ISC), SF Symbols лише всередині iOS-розширення.**

## Рішення

Варіант 2. Палітра «Реп'ях-цвіт» з обчисленими контрастами WCAG 2.2 AA для обох тем. Теми віджетів як нагороди реалізуються перевизначенням семантичних токенів. На Android віджет може перефарбовуватися Material You.

## Наслідки

Магічні значення у XAML вважаються дефектом. Потрібен генератор і CI-перевірка контрасту. Дизайн-QA чекліст входить у Definition of Done для UI-задач.
