# 0016. Косметичні нагороди, нарахування клієнтом зі звіркою сервером у v1

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-27 |
| Рішення журналу | Q34, Q24, T11, T17, T18 |
| Специфікації | 07, 09 |

## Контекст

Гейміфікація потрібна для звички, але власник хоче етичну модель без купівельної валюти й випадкових нагород. Серверно-авторитетне нарахування з першого дня подорожчує v1 і не потрібне, поки нагороди косметичні.

## Варіанти

1. Серверно-авторитетні нагороди з дня 1 з App Attest/Play Integrity.
2. **Клієнт нараховує за чистими `EconomyRules` (спільний пакет), пише append-only ledger, сервер перепрограє ті самі правила, відхиляє неможливі події й повертає корекції; перехід до серверного нарахування у v1.1.**
3. Лише бейджі без валюти.

## Рішення

Варіант 2. Валюта «колючки» витрачається лише на косметику (теми віджетів, вбрання Реп'яшка, рамки) і заморозку серії; не купується, не випадає випадково. Серія щоденна з однією безкоштовною заморозкою на тиждень, гнучкий режим доступний. Режим «без гейміфікації» першокласний.

## Наслідки

Спільний пакет правил має бути детермінованим і покритим property-тестами. Денні ліміти й перевірка зсуву годинника є єдиним антифродом у v1. Соціальні функції та ліги не реалізуються.
