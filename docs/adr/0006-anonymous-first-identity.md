# 0006. Анонімна ідентичність з опційною прив'язкою Apple/Google

| Поле | Значення |
|---|---|
| Статус | Accepted |
| Дата | 2026-09-27 |
| Рішення журналу | Q3, Q4, Q38 |
| Специфікації | 09, 10, 03 |

## Контекст

Потрібен обов'язковий сервер (синхронізація, нагороди, підписки), але власник не хоче бар'єра реєстрації і хоче мінімум даних. Apple вимагає, щоб застосунок був корисний без входу, і вимагає Sign in with Apple, якщо є Google.

## Варіанти

1. Обов'язкова реєстрація email/пароль. Мінус: бар'єр, персональні дані, правила NIST щодо паролів.
2. **Анонімний акаунт створюється сервером автоматично при першому запуску (UUID установки + автогенерований нікнейм). Прив'язка Sign in with Apple (і Google з релізом Android) лише для синхронізації між пристроями.**
3. Лише локально без сервера. Суперечить рішенню Q4.

## Рішення

Варіант 2. Токени доступу короткі (5-15 хв), refresh-токени ротуються з виявленням повторного використання. Об'єднання анонімного акаунта з провайдером, який уже має інший акаунт, виконується перепрограванням обох журналів подій із підтвердженням користувача. Видалення акаунта доступне в застосунку і через веб-посилання.

## Наслідки

Email не збирається; приватний relay Apple приймається. Прогрес прив'язаний до акаунта, тому втрата пристрою без прив'язки означає втрату прогресу, про що застосунок попереджає. Паролі не підтримуються у v1.
