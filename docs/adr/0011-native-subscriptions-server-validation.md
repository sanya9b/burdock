## Контекст

Freemium із тріалом через магазин. Потрібна крос-платформна перевірка entitlement-ів без передачі даних про покупки третім сторонам.

## Варіанти

1. RevenueCat. Швидкий старт, але третя сторона отримує дані про покупки й бере відсоток після порогу.
2. **StoreKit 2 / Google Play Billing на клієнті, перевірка транзакцій на сервері через App Store Server API та Play Developer API, вебхуки App Store Server Notifications V2 і RTDN.**
3. Лише клієнтська перевірка. Небезпечно при обов'язковому сервері.

## Рішення

Варіант 2. Сервер веде стан entitlement-у (Free, Trial, Active, Grace, BillingRetry, Expired, Revoked) і віддає його клієнту з TTL для офлайн-кешу. Продукти `org.burdock.app.pro.monthly` та `.yearly`, вступна пропозиція 7 днів безкоштовно.

## Наслідки

Потрібні ключі App Store Server API та сервісний акаунт Play у секретах. Тестування у sandbox входить у критерії готовності. Довічна й сімейна підписки не в v1.
