## Контекст

Один розробник, лише Windows, кілька складових (застосунок, сервер, контент, документація), спільні DTO та єдиний CI.

## Варіанти

1. Окремі репозиторії. Складніше синхронізувати контракти.
2. **Приватний монорепозиторій GitHub; trunk-based з короткими гілками; GitHub Actions: Linux для сервера/спільних шарів/Android, macOS-раннери для iOS зі знімками симулятора та публікацією в TestFlight; хмарний Mac погодинно для інтерактивного налагодження.**
3. GitLab/Azure DevOps. Немає готових macOS-раннерів у безкоштовних планах.

## Рішення

Варіант 2 із захищеною гілкою main, обов'язковими перевірками (збірка, тести, архітектурні тести, лінт локалізації, аудит залежностей). Купівля Mac mini переоцінюється через місяць роботи з CI-циклом.

## Наслідки

macOS-хвилини платні: бюджет закладено у специфікації 14. Swift-код перевіряється лише в CI, тому кожна зміна віджетів супроводжується знімками з артефактів.
